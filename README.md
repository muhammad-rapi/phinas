# Phinas

Pemutar musik desktop untuk dengar bareng teman (Mac dan Windows). / A desktop music player to listen with friends.

**Halaman unduh / Download page:** https://phinas.vercel.app

Versi terbaru / Latest version: https://github.com/muhammad-rapi/phinas/releases/latest

Installer belum ditandatangani, jadi muncul peringatan keamanan saat pertama dibuka. Langkahnya ada di halaman unduh. / The installers are not code-signed; see the download page for how to open them.

Phinas tidak berafiliasi dengan YouTube atau Spotify. / Phinas is not affiliated with YouTube or Spotify.

Situs web (halaman unduh, S&K, Privasi, panel admin) ada di folder `web/` (Next.js, Vercel). / The website lives in `web/`.
